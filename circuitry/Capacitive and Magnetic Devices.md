# Capacitive and Magnetic Devices（电容与磁器件）

> [!NOTE] 本笔记定位
> 把"**理想二端元件**"（[[Capacitor|电容]] $q=Cv$、[[Inductor|电感]] $\phi=Li$）连接到"**真实物理实现**"：MOS 栅电容的平行板结构、螺线管绕组电感的 $L=N^2\mu A/\ell$、以及互感与**变压器**的电磁耦合原理。
> 承上：[[Capacitor]]/[[Inductor]] 的物理来源；启下：[[Inductor]] 中的耦合电感/互感公式。
> 与 [[cs6.002x.1|知识树]] 互链。

## 一、为什么需要这一层物理？

之前两节笔记（[[Capacitor]] / [[Inductor]]）给出了理想元件的本构关系——但工程实践中要知道：

| 问题 | 回答 |
| :--- | :--- |
| 电容值 $C$ 是怎么来的？ | 由**几何结构**和**材料介电常数**决定 |
| 电感值 $L$ 是怎么来的？ | 由**绕组匝数**和**磁路几何**决定 |
| 电容/电感能无限大吗？ | 受限于面积/体积、成本、寄生参数 |
| 变压器如何工作？ | 靠**互感**而非欧姆连接传递能量 |

## 二、MOS 栅电容 (MOS Gate Capacitance)

### 2.1 平行板结构

MOSFET 的栅极–氧化层–沟道构成一个平行板电容：

![[mos_gate_cap.svg]]

- **上极板 (Top plate)**：金属栅极 (Gate / polysilicon)
- **电介质 (Dielectric)**：二氧化硅绝缘层，厚度 $t_{ox}$，介电常数 $\varepsilon_{ox}$
- **下极板 (Bottom plate)**：半导体沟道 (Channel / Si substrate)

### 2.2 单位面积电容

$$\boxed{C_{ox} = \frac{\varepsilon_{ox}}{t_{ox}} \quad \left[\text{F/m}^2\right]}$$

> [!IMPORTANT] 物理直觉
> $t_{ox}$ 越薄 → $C_{ox}$ 越大 → 栅控能力越强（这也是摩尔定律不断缩小 $t_{ox}$ 的动力）。但 $t_{ox}$ 过薄会产生**栅极漏电 (gate leakage)**，是先进工艺面临的主要挑战之一。

### 2.3 总栅电容

$$C_{gg} = C_{ox}\,W\,L = \frac{\varepsilon_{ox}WL}{t_{ox}}$$

- $W$：**沟道宽度**，增大 $W$ → 栅宽增加 → 电容增大
- $L$：**沟道长度**，决定器件尺寸比例

### 2.4 电容的频率特性（非理想效应）

> [!NOTE] 三种电容分量
> 实际 MOSFET 有三个电容：
> - $C_{gs}$：栅–源电容（输入电容的直接组成部分，**不受**密勒放大）
> - $C_{gd}$：栅–漏电容（跨接在反相放大器输入输出之间，**Miller 效应的关键来源**：等效输入电容 $\approx (1+|A_v|)C_{gd}$）
> - $C_{gb}$：栅–体（衬底）电容（弱反型时显著）
>
> 这三个电容直接决定[[Small Signal Circuit Representation|MOSFET 小信号]]的**高频性能**（密勒效应）。

## 三、绕组电感 (Wound Inductor)

### 3.1 螺线管理想电感公式

$$\boxed{L = \frac{N^2\mu A}{\ell} \quad \text{[H]}}$$

| 符号 | 含义 | 物理意义 |
| :--- | :--- | :--- |
| $N$ | 匝数 | 线圈总匝数，**平方关系**（最敏感的参数） |
| $\mu$ | 磁导率 | 材料属性，$\mu=\mu_r\mu_0$；铁芯 $\mu_r\gg 1$ 可达 $10^3$–$10^5$ |
| $A$ | 线圈截面积 | 线圈半径平方 $\pi r^2$ |
| $\ell$ | 磁路平均长度 | 线圈轴向长度 |

> [!TIP] 设计电感的核心逻辑
> 想增大 $L$？最有效的方法是**增加匝数 $N$**（平方关系），或加**磁芯**（提高 $\mu_r$）。但 $N$ 增大也增加导线电阻 $R_{DC}$、集肤效应损耗、寄生电容——又是工程折中。

### 3.2 磁芯材料与损耗

| 材料 | $\mu_r$ 典型值 | 适用频率 | 损耗 |
| :--- | :--- | :--- | :--- |
| 空气（无磁芯） | 1 | 任意 | 极低 |
| 铁氧体 (Ferrite) | $10^2$–$10^3$ | kHz–MHz | 低 |
| 硅钢 (Si Steel) | $10^3$–$10^4$ | 50/60 Hz | 中等 |
| 非晶/纳米晶 | $10^4$–$10^5$ | kHz–100kHz | 低 |

**磁芯损耗**：磁滞损耗（与磁通密度摆幅有关）+ 涡流损耗（与频率和材料电阻率有关）。

### 3.3 寄生参数（非理想电感）

真实电感的等效结构：**$R_{\text{DC}}$ 与 $L_{\text{理想}}$ 串联**，整体再与 $C_{\text{寄生}}$ **并联**。

- $R_{\text{DC}}$：线圈铜耗（直流电阻）
- $C_{\text{寄生}}$：匝间电容（与 $N^2$ 相关，高频下导致**自谐振**）
- 自谐振频率：$f_{SRF} = \frac{1}{2\pi\sqrt{LC_{\text{寄生}}}}$

> [!WARNING] 自谐振频率
> 在 $f_{SRF}$ 以上，电感表现为**电容性**（电感特性消失）。这是使用绕组电感时必须检查的频率上限。

## 四、互感与变压器 (Mutual Inductance / Transformer)

### 4.1 互感的定义

两个相邻线圈，线圈 1 的电流 $i_1$ 在线圈 2 中产生的磁通为 $\Phi_{21}$：

$$\boxed{M = \frac{N_2\Phi_{21}}{i_1} = \frac{N_1\Phi_{12}}{i_2} \quad \text{[H]}}$$

互感 $M$ 是描述**磁耦合强度**的核心参数。

### 4.2 耦合系数 $k$

$$k = \frac{M}{\sqrt{L_1L_2}}, \qquad 0 \le k \le 1$$

| $k$ 值 | 耦合程度 | 典型应用 |
| :--- | :--- | :--- |
| $k\approx 1$ | 紧耦合（理想变压器） | 电源变压器、隔离变压器 |
| $k\approx 0.5$ | 松耦合 | 射频变压器、感应耦合 |
| $k\approx 0$ | 几乎无耦合 | 独立电感（无互感） |

### 4.3 互感电压

$$\boxed{v_2 = M\,\frac{di_1}{dt}}$$

当线圈 1 电流变化时，线圈 2 两端感应出与电流变化率成正比的电压——这就是**变压器**工作的本质（无导线连接，却能传递能量）。

## 五、变压器 (Transformer)

### 5.1 理想变压器方程

![[transformer.svg]]

| 方程 | 含义 |
| :--- | :--- |
| $\dfrac{v_1}{v_2} = \dfrac{N_1}{N_2}$ | 电压比等于匝数比 |
| $\dfrac{i_1}{i_2} = \dfrac{N_2}{N_1}$ | 电流比与匝数比成反比 |
| $v_1 i_1 = v_2 i_2$ | 功率守恒（理想变压器不储能/不耗能） |

> [!NOTE] 变压器的核心功能
> 1. **变压**：改变 AC 电压等级（电力传输的核心）
> 2. **隔离**：原边与副边无导线连接（安全隔离）
> 3. **阻抗变换**：$Z_{\text{in}} = \left(\frac{N_1}{N_2}\right)^2 Z_L$（在 [[Maximum Power Transfer Theorem|最大功率传输]] 中有重要应用）

### 5.2 实际变压器的损耗

| 损耗类型 | 来源 | 对应电路模型 |
| :--- | :--- | :--- |
| 铜耗 ($I^2R$) | 线圈电阻 | $R_1, R_2$（串联） |
| 铁芯损耗 | 磁滞 + 涡流 | $R_{\text{core}}$（并联） |
| 漏感 | 非理想耦合（部分磁通不交链） | $L_{\sigma 1}, L_{\sigma 2}$（串联） |
| 寄生电容 | 匝间电容 | $C_{\text{winding}}$（并联） |
